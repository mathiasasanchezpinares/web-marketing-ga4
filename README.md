# Café Andino — Web de prueba para Marketing Digital

Sitio web estático ficticio para practicar:

- GitHub Pages
- Google Tag Manager (GTM)
- Google Analytics 4 (GA4)
- Eventos y conversiones
- Análisis de comportamiento

## Páginas

- `index.html`
- `productos.html`
- `nosotros.html`
- `contacto.html`

## Acciones preparadas para medir

- Visitas a páginas
- Clic en Ver productos
- Clic en Contacto
- Clic en Agregar al carrito
- Evento personalizado `add_to_cart_demo`
- Envío de formulario
- Evento personalizado `generate_lead_demo`
- Clic en WhatsApp
- Clic en email

## Importante

No hay ningún ID de GA4 ni GTM instalado. El objetivo del taller es que los estudiantes los agreguen durante la clase.
